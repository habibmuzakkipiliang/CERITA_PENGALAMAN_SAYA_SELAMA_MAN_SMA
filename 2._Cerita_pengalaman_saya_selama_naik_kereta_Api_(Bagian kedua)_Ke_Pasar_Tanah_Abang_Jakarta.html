Catatan : KRL Commuter Line adalah kereta rel listrik yang melayani perjalanan dari Rangkasbitung menuju wilayah Jabodetabek (Jakarta, Bogor, Depok, Tangerang, dan Bekasi). Sementara itu, kereta api diesel (KRD) adalah kereta api berbahan bakar diesel yang melayani perjalanan dari Rangkasbitung menuju Walantaka (Petir), Serang , Cilegon, dan Merak.

Pada Kamis, 20 Agustus 2026, saya pergi ke Jakarta (Pasar Tanah Abang) bersama Ayah dan Bunda, saya berangkat dari rumah pada pukul 05.15 WIB setelah sholat subuh, sampai di stasiun pada pukul 05.30 WIB, dan saya nunggu kereta api diesel (KAI) selama kira-kira 25 menit, dan berangkat dari Stasiun Serang ke Stasiun Rangkasbitung pada pukul 05.50 WIB, dan lama perjalanan nya selama kira-kira 1 jam. Sampai disana (Stasiun Rangkasbitung) pada pukul 07.00 WIB

Lalu saya pun Naik KRL (Kereta Api Listrik) pada pukul 07.10 WIB, lama perjalanan kira-kira 2 jam, sampai di Stasiun Tanah Abang pada pukul 09.10 WIB, saya dan keluarga pun langsung naik ke Jembatan Penyebrangan Orang (Skybridge Tanah Abang). Lalu, pergi ke Warung Nasi Alam Sunda, Tanah Abang, Jakarta
